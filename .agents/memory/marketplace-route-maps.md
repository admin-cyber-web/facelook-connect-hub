---
name: Marketplace route maps
description: User-chosen route accuracy scope for marketplace shipment maps.
---

Marketplace route displays should remain illustrative schematics with generic intermediate hubs, not be presented as road-accurate directions.

**Why:** The user explicitly selected an approximate schematic instead of public OSRM routing or connecting a production provider.

**How to apply:** Keep the route labeled as illustrative and not to scale. Ask before replacing it with a road-routing service.
