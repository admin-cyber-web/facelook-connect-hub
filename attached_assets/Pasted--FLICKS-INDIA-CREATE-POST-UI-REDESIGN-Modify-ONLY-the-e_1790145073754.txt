## FLICKS INDIA — CREATE POST UI REDESIGN

Modify ONLY the existing **Create Post / Post Composer system** of Flicks India.

### IMPORTANT

* Do NOT remove, disable, rename, or break any existing post functionality.
* Do NOT rewrite the post system from scratch.
* Do NOT change Supabase logic, authentication, posting API, database schema, AI logic, media upload logic, permissions, privacy logic, tagging logic, or existing post behavior.
