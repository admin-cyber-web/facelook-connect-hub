* Frontend: React + Vite

* Domain: https://www.flicksindia.online

GOAL:
Fix Google Search Console "Discovered – Currently Not Indexed" issue and make every public post fully SEO-friendly and indexable.

IMPLEMENT ALL OF THE FOLLOWING:

1. DYNAMIC SEO FOR EVERY POST

Every public post page must automatically generate:

* SEO title
* Meta description
* Open Graph tags
* Twitter Card tags
* Canonical URL

Example output:

<title>{postTitle} | Flicks India</title>

<meta name="description" content="{postDescription}" />

<meta property="og:title" content="{postTitle}" />
<meta property="og:description" content="{postDescription}" />
<meta property="og:image" content="{postThumbnail}" />
<meta property="og:url" content="{postUrl}" />

<meta name="twitter:title" content="{postTitle}" />
<meta name="twitter:description" content="{postDescription}" />
<meta name="twitter:image" content="{postThumbnail}" />

<link rel="canonical" href="{postUrl}" />

2. AUTO TITLE GENERATION

If user enters a title:
Use the title.

If user does not enter a title:
Generate title automatically from first 60 characters of caption.

Examples:

Caption:
"My first trip to Goa was amazing"

"My First Trip To Goa Was Amazing | Flicks India"

Short captions:
Use available text.

Never leave title empty.

Visible image/video

Visible description
