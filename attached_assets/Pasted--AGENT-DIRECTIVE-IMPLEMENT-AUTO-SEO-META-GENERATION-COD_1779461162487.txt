The `posts` table has been successfully updated with the new columns: `meta_title`, `meta_description`, and `seo_keywords`. You must now integrate the frontend logic to automatically generate and save this metadata upon post creation using the Gemini SDK.

- Use the Gemini model (preferably gemini-1.5-flash or gemini-2.5-flash) to analyze the post content.

    "meta_title": "SEO Optimized Title (max 60 chars)",

    "seo_keywords": "comma, separated, trending, search, terms"

## 3. BANDWIDTH CONSERVATION & ANTI-LEAK AUDIT
- Under no circumstances should these metadata attributes trigger automatic recurring AI fetching logic on the feed.
