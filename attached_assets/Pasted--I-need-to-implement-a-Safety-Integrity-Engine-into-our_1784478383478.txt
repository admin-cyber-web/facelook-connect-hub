Send an automated, privacy-conscious system notification to the 'Protected' user: 'Warning: Your partner's communication pattern shows suspicious inconsistencies.' (Do not show the actual chat content to maintain privacy).

Task 4: Database Requirements

Design a SQL schema that includes:

UserRiskProfile (user_id, risk_score, is_flagged).

MessageHistory (sender_id, receiver_id, message_content, timestamp).

LoveProtectLinks (user_id, partner_id, is_active).

All logic must run on the backend to ensure security cannot be bypassed by the client.
